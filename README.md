# 拼多多 AI 客服商业版

[下载最新版本](https://github.com/xgq947-ship-it/pddai-releases/releases/latest)

本仓库仅发布安装包、签名、更新清单和简要版本说明，商业源码保持私有。

## 1.0.0

支持多店铺 AI 接待、商品知识与图解资料、售后处理、人工审核、订单协同及聚水潭插件接入，内置商业授权与软件更新。

本次先发布 Mac Apple 芯片版，适用于 macOS 11.0 及以上；下载 `.dmg` 并拖入「应用程序」。Windows 64 位安装包后续追加到同一版本。

Mac 安装包使用项目本地证书签名，未经 Apple 公证。在线更新包使用独立更新密钥签名并由客户端验签。

更新入口为「设置 → 软件更新」，默认清单：[latest.json](https://github.com/xgq947-ship-it/pddai-releases/releases/latest/download/latest.json)。先下载并验签，再安装；本机设置、授权和业务数据保留。

Release 附 `SHA256SUMS.txt`，可核对下载文件完整性。
