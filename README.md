# 拼多多 AI 客服商业版发布

本仓库用于公开分发 Windows / macOS 安装包、更新清单和版本说明。商业版源码和构建密钥不在此仓库。

目前尚未发布首个版本，也没有启动构建。

后续每个正式 Release 包含：

- Windows 安装包 / macOS 更新包及其签名。
- `latest.json`：版本、发布时间、简要更新说明和各系统下载地址。
- Release 说明：新增功能、问题修复和界面调整。

客户端在「设置 → 软件更新」中检查和安装。先下载并验证签名，再暂停后台完成安装，保留本机设置、授权和业务数据。

构建在商业源码仓库或专用构建机执行，签名私钥仅存构建环境；本仓库接收构建后的发布文件。没有真实安装包和签名时，不创建占位更新清单。
